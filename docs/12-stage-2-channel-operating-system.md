# Stage 2 — Channel Operating System (COS)

## Purpose
Define the **Standard Operating Procedure** that runs the business every day. Where Stage 1.5 decided *what* to build, Stage 2 defines *how to operate* it — for speed, automation, consistency, and scale. It is deliberately **Shorts-first** (Phase 1).

## Inputs
- [Stage 1](10-stage-1-competitor-intelligence.md) and [Stage 1.5](11-stage-1_5-business-decisions.md).

## Outputs
Twelve operating sections: company blueprint, Shorts content framework, channel bible, content engine, script SOP, asset management, production pipeline SOP, quality control, KPI dashboard, automation roadmap, scaling roadmap, and an executive playbook.

## Non-negotiable rules
- No video ships without a genuine twist.
- No lifted memes, music, or IP — original assets only.
- Advertiser-safe (no gore/unsafe humor).
- Every asset must be reusable; human-check punchline + QC before publish.
- 100% upload cadence — the schedule is sacred.

## The 5-Gate decision test
Every future decision must pass all five, or be rejected:
1. Increases speed/volume?
2. Reusable / scales?
3. Protects originality/monetization?
4. Low-cost in Phase 1?
5. Improves retention/CTR?

Failing gate 1, 2, or 3 → reject.

## Shorts content framework (measurable)

| Spec | Standard |
|---|---|
| Duration | 25–40s |
| Hook | 0–2s |
| Twist | 28–36s |
| Ending | Hard cut, ≤1s tail |
| Words per second | 2.5–3.0 (≈75–120 words) |
| Scene count | 3–5 |
| Shot length | 2–4s |
| 3s retention (min) | ≥70% |
| Completion (min) | ≥45% |
| Production time target | ≤45 min (Phase 1) → ≤30 min |
| Weekly output | 10–14 Shorts |

## Content engine
Ideas come from a **twist-archetype bank** (6 archetypes), everyday observation, and trends (used only as a setup skin). Ideas are scored (produce only if ≥18/25) and stored in a database with a naming convention and lifecycle. Always keep ≥2 weeks of approved ideas buffered.

## Reusable asset library
Folder hierarchy, `IPPA_[####]_[premise]_[platform]_v#` naming, character versioning, background/prop/expression packs, cleared music/SFX, backup (3-2-1), and a **reuse-first mandate**. This is the entire cost moat: after a 2-week build, per-video work collapses to *script + pick presets*.

## Quality control
An 11-point Publish Gate (script, comedy, animation, timing, visual clarity, brand, voice, audio, retention, metadata, originality/safety). One failure blocks publishing.

## KPI dashboard + decision trees
Weekly metrics with thresholds and if/then actions (e.g., retention <45% → fix hook if 3s low, else strengthen/retire the twist type).

## Automation roadmap (by ROI)
1. Publishing/scheduling/metadata · 2. Idea generation + scoring · 3. Voice · 4. Analytics · 5. Script drafting · 6. Captions · 7. Thumbnails · 8. Animation assembly · 9. Feedback loop.

## Scaling roadmap
Stage A Solo → B Monetized → C Small team → D Multiple channels → E AI content studio.

## Dependencies

## Expected deliverables
A complete SOP a new hire could operate from, ending in a one-page printable operating manual.

## Success criteria
- Reduces future decision-making.
- Another person can operate the business from this document alone.
- Every workflow scales and is Shorts-first.

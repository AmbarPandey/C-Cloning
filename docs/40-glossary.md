# Glossary

Authoritative definitions for every term used across the C-Cloning system.

## Core concepts

| Term | Definition |
|---|---|
| **Faceless channel** | A channel with no on-camera human presence; content is fully animated/synthesized. |
| **Viral Formula** | A reusable narrative-psychological structure that reliably produces a predictable emotional reaction, independent of topic. See [Library 1](../intelligence/01-viral-formula-library.md). |
| **Comedy Mechanic** | A repeatable cognitive process that causes laughter by safely violating an expectation. See [Library 2](../intelligence/02-comedy-mechanics-library.md). |
| **Narrative Twist** | The engineered moment where an established prediction is replaced by a different-but-inevitable reality. See [Library 3](../intelligence/03-narrative-twist-library.md). |
| **Scenario** | A reusable social situation pre-loaded with expectation, roles, and conflict. See [Library 4](../intelligence/04-scenario-intelligence-library.md). |
| **Viewer Behavior** | A measurable viewer action (watch, replay, share, comment, subscribe). See [Library 5](../intelligence/05-viewer-psychology-library.md). |
| **Narrative Pattern** | A complete, reusable story algorithm assembling scenario + comedy + twist + behavior. See [Library 6](../intelligence/06-narrative-pattern-library.md). |
| **Seed** | A subtle clue planted early that the twist pays off; the engine of replay. |
| **Benign violation** | An expectation violation perceived as safe/non-threatening — the condition for laughter. |

| Term | Definition |
|---|---|

| **Intelligence Layer** | Library 7: the queryable knowledge graph. |
| **Computation Layer** | Library 8: the deterministic combination engine. |

| **Production Layer** | Stages 5–6: compiles briefs into scripts and production assets. |

## The Plot-Twist Formula (Library 1)

| Beat | Meaning |
|---|---|
| Hook | Recognizable opener that wins the first 3 seconds. |
| False Comfort | Confirms the viewer's prediction to set the trap. |
| Escalation | Raises stakes to build anticipation. |
| Pattern Break | First "something's off" beat; re-hooks attention. |
| Twist | The prediction-error payload. |
| Hard Cut | Ends on the reveal; no wind-down. |

## Scoring terms

| Term | Definition |
|---|---|
| **Compatibility** | Scored strength (1–5) of a link between two adjacent-layer nodes. |
| **Confidence** | Trust level of a record: High (1.0) / Med (0.7) / Low (0.4). Only real analytics promote it. |
| **Virality Potential** | `0.30·Share + 0.25·Replay + 0.20·Evergreen + 0.15·AdSafe + 0.10·Ease`. |
| **Combo / Final Score** | `ViralityPotential × CompatibilityChain × Confidence − DifficultyPenalty`. Sort key for production. |
| **Evidence tag** | `[O]` Observed (seen in Stage 1 analysis) or `[I]` Inference (generalized). |

## Business terms

| Term | Definition |
|---|---|
| **YPP** | YouTube Partner Program (monetization). |
| **RPM** | Revenue per mille (per 1,000 views). |
| **Advertiser-safe / AdSafe** | Content that does not trigger ad limitations (no gore, no unsafe humor). |
| **Recurring cast** | The fixed set of ~4 characters used across all videos to build loyalty. |
| **Mute-readable** | The video's meaning is fully clear with sound off. |

# Stage 5 — Script Compiler

## Purpose
Compile exactly **one** Stage 4 idea brief into a **production-ready Shorts script**. This is a *compiler*, not a writer: every line exists to satisfy a verified objective, and the brief's locked parameters are immutable.

## Inputs
- Exactly one idea brief from [Stage 4](13-stage-4-idea-generator.md).

## Outputs
1. Compilation summary (restating and honoring the locked inputs).
2. Beat sheet (time range, narrative purpose, viewer-psych objective, comedy objective, twist prep, expected reaction).
3. Production script (per scene: time, visual, character action, dialogue, narration, SFX, emotion, library refs).
4. Retention audit.
5. Replay audit (seeds, foreshadowing, callbacks).
6. QA scorecard (pass/fail per library).
7. Optimization suggestions (retention/replay/share/comment only).
8. Final production package summary.

## Compilation rules
- Immutable: Business Goal, Behavior, Pattern, Scenario, Comedy Mechanic, Twist, Formula, Compatibility, Confidence, Priority.
- If a brief contains an issue → **report it**, do not silently fix or substitute.
- Keep dialogue minimal; optimize for visual, mute-friendly viewing; maintain advertiser safety.

## Internal logic
Maps the brief's pattern/scenario/comedy/twist onto the Plot-Twist Formula beats, plants a seed for replay, ensures mute-readability, routes through the recurring cast, and ends on a hard cut. Then it audits itself against every library and produces a pass/fail QA scorecard.

## Worked example — Idea A1
- **Path:** Reach → Share → NP1 Comeuppance → SC1 Authority → Overconfidence Collapse → Instant Karma → Plot-Twist.
- **Premise:** A smug authority-figure cast member abuses power over a smaller Pal; their own overconfident final flex instantly backfires and punishes them.
- **Cast:** CHIEF (authority) + PIP (underdog).
- **Result:** 8 scenes, ~32s, 0 spoken words, QA 10/10 → **Production Ready**.
- **Seed:** CHIEF's own vehicle parked in the no-parking zone in frame 1, paid off when the tow truck hauls *him* away via his own tool.

## Dependencies
[Stage 4](13-stage-4-idea-generator.md); audits against [Libraries 1–8](../intelligence/README.md).

## How it connects to other stages
An approved script is the immutable input to [Stage 6 — Production Compiler](15-stage-6-production-compiler.md).

## Expected deliverables
One compiled script per brief, ending in **Production Ready** or **Needs Revision** with justification.

## Success criteria
- Every scene exists for a measurable, traceable reason.
- Another AI produces the same script from the same brief.
- No idea parameters altered.

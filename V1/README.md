# V1 — Video 1 (Series Opener)

This folder is a **self-contained, copy-paste-ready** package to produce your first video. You do
not need to read the rest of the repo to use it — everything you need is inside `V1/`.

> **What V1 is:** the series-opening ~30-second vertical (9:16) animated comedy Short.
> **Format:** mute-first, twist-ending, advertiser-safe. **Cast:** the two recurring characters
> (**PIP** and **CHIEF**) whose identity you are building across the whole series.
> **Story in one line:** a pompous parking officer (CHIEF) bullies a tiny, lovable underdog (PIP)…
> then karma tows away CHIEF's *own* illegally parked scooter using his *own* boot.

## How to make the video (simple, non-technical steps)

1. **Build the cast once.** Open [02-characters-and-reactions.md](02-characters-and-reactions.md),
   paste each prompt into your image tool, and save the character **reference sheets** + reaction images.
   *(You reuse these in every future video — this is how the character identity is built.)*
2. **Make the scene images.** Open [04-image-prompts.md](04-image-prompts.md). For each shot, paste
   the prompt into your image tool **using your character reference** so the characters stay identical.
3. **Turn images into motion.** Open [05-video-prompts.md](05-video-prompts.md). Feed each scene
   image + its motion prompt into your image→video tool. You now have 8 short clips.
4. **Add sound.** Follow [03-audio.md](03-audio.md): drop in the music bed, the silence beat, and
   the sound effects at the listed timestamps.
5. **Assemble & check.** Put the 8 clips in order, keep it ~30s, make the last frame match the first
   (loop). Run the quick check in [07-production-checklist.md](07-production-checklist.md).
6. **Publish.** Use the title/description/hashtags/thumbnail in [06-publish-package.md](06-publish-package.md).

## Important for the series
Do **not** redesign PIP or CHIEF between videos. Always start from the **same saved reference
images**. See [08-series-bible.md](08-series-bible.md) for the locked identity rules.

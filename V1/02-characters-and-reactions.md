# V1 — Characters & Reactions (Reference-Image Prompts)

These are your **recurring characters**. Generate their reference sheets **once**, save them, and
**reuse the same saved images in every future video** — that is how you build the character
identity for the series. Do not redesign them per video.

> **How to use this file**
> 1. Paste each **Reference Sheet prompt** into your image tool → save the result as the character's master reference.
> 2. Paste each **Reaction/Expression prompt** → save each as a separate labeled image.
> 3. In every scene and every future video, generate images **using these saved references** (as a
>    reference/style image or seed) so the character looks identical every time.

## Shared style (paste this at the top of EVERY prompt)
```
Flat-color 2D cartoon character, thick uniform black outlines, no gradients, minimal single-tone
shading, chunky proportions (about 2.5 heads tall), big expressive eyes, high contrast, clean vector
look, plain off-white background, full body, centered, mobile-legible.
Palette: ink #1A1A1A, brand yellow #FFD400, warm paper #FFF7E0, sky blue #BFE3F2, asphalt grey
#6E7076, alert red #E4322B, teal #2FB6A3. Advertiser-safe, wholesome, no text.
```

**Who PIP is:** small, gentle, kind, easily bullied but quietly dignified. The audience-favorite the
viewers root for. PIP never fights back — the *twist* delivers justice, so PIP stays likeable. **PIP
is the face of the series/channel.**

### Reference sheet — PIP (generate first)
```

black outline. Character turnaround: front view, 3/4 view, and side view, same character, consistent
```

## Consistency tips (so they look identical every time)
- Always feed the tool your **saved reference sheet** for that character (reference-image / "character
  reference" / same seed), not just the text.
- Keep **CHIEF's cap + sash + medals** and **PIP's teal scarf** in every shot — they are the silhouettes.
- Lock the palette hex values in every prompt.
- If a result looks "off-model" (wrong colors, gradients, different proportions), regenerate — do not
  settle, because consistency is the whole brand.

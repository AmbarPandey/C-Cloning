# v3 — "One Block Too Many" (production package)

A complete, cross-synced YouTube Shorts package for video **v3**, built from the locked A3 idea
(NP3 Overreach Collapse · SC3 Competition · CM-C2 Overconfidence · TW4 False Victory · FinalScore 8.9).
Cast: **CHIEF** (overreaching braggart) vs **PIP** (careful underdog). ~32 s, 9:16, mute-first with an
optional VO layer. **Video ID:** `IPPA_0003_tower_shorts_v1`.

All 5 files below lock to the **same master timeline** (defined in `01-video-script.md`), so the
render, narration, and audio drop straight onto shared timecodes — designed for minimal editing.
The timeline uses the **same 8-clip / 32-second / 11-second-silence skeleton as v1 and v2**, so the
series stays formulaic and repeatable.

**Story in one line:** a block-stacking contest — build to the red line and keep it standing. PIP stops
exactly at the line; CHIEF can't stop at "enough," builds a teetering monstrosity, climbs it, seizes the
trophy and celebrates a total victory — then the one crooked block he slapped down at the start gives way.

**The seeds:** the **red target band + yellow arrow** on the measuring post (frame 1) that defines the
goal; and the **crooked bottom block** CHIEF carelessly drops in the setup — the exact block that buckles.

**What makes v3 different from v1/v2:** the twist core is **False Victory** — CHIEF genuinely *wins* and
fully celebrates on screen (trophy, confetti, hero pose) before the win is revealed as void. v1 punished
him (Instant Karma), v2 swapped their roles (Role Reversal); v3 **gives him the prize and then takes it
away.** The whole craft challenge is selling the celebration completely at 0:16 so the collapse has
something real to destroy.

> ⚠️ **Freshness flag:** A3 reuses **SC3 Competition**, the same scenario archetype as v2. Mitigation and
> a rotation option are documented at the bottom of [`01-video-script.md`](01-video-script.md).

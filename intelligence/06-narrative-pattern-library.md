# Library 6 — Narrative Pattern Library

## Purpose
The **integration layer**: combine Libraries 1–5 into complete, reusable *story algorithms*. A pattern is a function; a story is its output.

## Positioning
- [Library 1](01-viral-formula-library.md) is the universal **skeleton**.
- A Narrative Pattern is a **named species** of that skeleton with a pre-selected scenario, comedy mechanic, twist, and target behavior.

## Knowledge stored

### 8 patterns in 3 tiers
| Tier | Patterns |
|---|---|
| **Daily engines** | NP1 Comeuppance · NP2 Underdog Reversal · NP3 Overreach Collapse |
| **Premium / replay** | NP4 Hidden Truth · NP7 Bait-and-Switch |
| **Variety** | NP5 Escalating Disaster · NP8 Ironic Backfire · NP6 Literal Trap (low-priority) |

### Universal pattern spine
`Scenario → Expectation → Conflict → Escalation → Comedy → Seed → Twist → Behavior Trigger → Hard Ending`

## The Company Standard (locked) — "The Unified Story Algorithm (USA)"
The single machine all 8 patterns plug into:
1. Select pattern · 2. Drop into a status-gap scenario · 3. Set the wrong expectation · 4. Escalate · 5. Seed · 6. Twist (one core) · 7. Trigger the target behavior · 8. Hard cut. Constraints: one pattern, one twist core, reads muted, recurring cast, advertiser-safe.

### Pattern → goal selection
- Want Share/Comment → NP1/NP2 · Want spectacle Share → NP3/NP5 · Want Replay → NP4/NP7 · Want Subscribe → NP2 with cast lead.

## Relationships
Consumes Scenario ([L4](04-scenario-intelligence-library.md)), Comedy ([L2](02-comedy-mechanics-library.md)), Twist ([L3](03-narrative-twist-library.md)), Behavior ([L5](05-viewer-psychology-library.md)); runs the Formula ([L1](01-viral-formula-library.md)).

## How later stages consume it
The Content Matrix selects exactly one `NP` node as Layer 2 of the funnel; it is the backbone of every generated idea.

## Examples
Idea A1 uses **NP1 Comeuppance** (wrongdoing → escalation → instant payback).

## Important decisions
- One pattern per video; never mix two.
- Check pattern↔scenario compatibility *before* writing — the dominant pattern-level failure is a mismatch (e.g., heavy reframe on a low-stakes scene).
- NP6 Literal Trap is demoted to flavor (predictability ceiling).

# Template — Publishing Metadata (Title / Description / Hashtags)

Reusable formulas for the publishing package. Fills audit finding **F6**. Filled example:
[A1 publish package](../A1-first-video/08-publish-package.md).

## Title formula
```
<curiosity hook that implies a twist, no spoiler> <1 emoji> #shorts
```
- ≤ ~60 characters. Promise a payoff; never reveal *how*. Exactly one emoji. Always end `#shorts`.
- Keep 2 alternates for A/B testing.

## Description formula
```
<1-line hook restating the premise + payoff> <emoji>
<1-line replay nudge that points at the seed> 👀

<channel line> <1-line comment prompt> 👇

<hashtag block>
```

## Hashtag set (channel default — reuse)
```
#shorts #animation #cartoon #comedy #plottwist #karma #funny #instantkarma #satisfying #toon
```
Structure = 1 format + 3 genre + 3 twist/payoff + 3 discovery (10 total). Swap the 3 twist/payoff
tags to match the specific video's twist type if needed.

## Settings block (fill per video)
| Field | Value |
|---|---|
| Category | Comedy / Film & Animation |
| Playlist | "IPPA — All Shorts" |
| Visibility | Scheduled (batch) |
| Made-for-kids | Set per channel policy (advertiser-safe general audience) |
| Cadence slot | 1 of 10–14/week |

## Rules (from Stage 2)
- Advertiser-safe language only.
- No spoilers of the twist mechanic in title/thumbnail.
- The description's replay nudge should reference the **seed** to drive rewatches.

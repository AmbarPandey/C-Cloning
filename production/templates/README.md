# Templates — Reusable Production Artifacts

Blank, reusable templates so every future video is produced the same way A1 was. Copy a template,
fill it, and store the filled copy under `production/<IdeaID>-.../`.

| Template | Purpose | First filled use |
|---|---|---|
| [visual-prompt-template.md](visual-prompt-template.md) | Standard image/scene render prompt (style prefix + slots) | [A1 storyboard](../A1-first-video/03-storyboard.md) |
| [thumbnail-spec.md](thumbnail-spec.md) | Thumbnail composition + export rules | [A1 publish package](../A1-first-video/08-publish-package.md) |
| [metadata-template.md](metadata-template.md) | Title / description / hashtag formulas | [A1 publish package](../A1-first-video/08-publish-package.md) |
| [editing-timeline-template.md](editing-timeline-template.md) | Timeline / cut / caption / loop-seam checklist | [A1 editing spec](../A1-first-video/07-editing-spec.md) |
| [publish-gate-checklist.md](publish-gate-checklist.md) | Blank 11-point Publish Gate | [A1 checklist](../A1-first-video/10-production-checklist.md) |

All templates inherit the [cast style guide](../characters/cast-style-guide.md) and the
[Stage 2](../../docs/12-stage-2-channel-operating-system.md) standards. They instantiate the locked
design; they do not change it.
